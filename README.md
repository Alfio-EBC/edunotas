# EduNotas

### Gestor de notas, tareas y comunicación académica

**EduNotas** es una aplicación web desarrollada para facilitar la gestión académica de estudiantes, profesores y padres de familia.

El proyecto permite registrar y consultar información académica, asignar tareas, visualizar fechas de entrega mediante un calendario y facilitar la comunicación entre profesores y padres.

## 🚀 Funcionalidades

* 📝 Registro y gestión de notas.
* 📚 Asignación de tareas por grado y grupo.
* 📅 Calendario de tareas y fechas de entrega.
* 👨‍🏫 Gestión de información de profesores.
* 👨‍👩‍👧 Comunicación entre profesores y padres.
* 💬 Envío de respuestas y observaciones.
* 📎 Carga de información relacionada con las tareas.
* 🗑️ Eliminación de registros.
* 💾 Almacenamiento de información mediante `localStorage`.
* 📱 Diseño adaptable a diferentes dispositivos.

## 🛠️ Tecnologías utilizadas

* **HTML5** – Estructura de la aplicación.
* **CSS3** – Diseño y estilos de la interfaz.
* **JavaScript** – Lógica, interacción y gestión de datos.
* **LocalStorage** – Persistencia de información en el navegador.
* **Lucide Icons** – Iconografía de la interfaz.
* **Git y GitHub** – Control de versiones y publicación del proyecto.
